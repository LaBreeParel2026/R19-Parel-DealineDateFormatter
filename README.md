# Deadline and Date Formatter

## Description
This Python program asks for event details and displays the deadline in a readable format.

## Versions

### Version 1 – Basic Input and Output
- Asks for the event title.
- Asks for the year, month, and day.
- Displays the entered information.
- Converts the event title to uppercase.

### Version 2 – Date Formatting
- Uses Python's datetime library.
- Displays the date in a readable format.
- Shows the year, month, and day.
- Displays the weekday of the event.

## Requirements
- Python 3
- VS Code or another Python coding platform

## How to Run
1. Download or clone this repository.
2. Open the files in VS Code.
3. Run `deadline_formatter_v1.py` or `deadline_formatter_v2.py`.
4. Enter the requested event details.
